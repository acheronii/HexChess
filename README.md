# HexChess
HexChess: A game of chess played on a Hexagonal board.

Runs via a Python and Django backend and Javascript/SVG front end connected by WebSockets via Redis.

## How to access
Available [online](https://hexchess-1.azurewebsites.net)

Alternatively, run locally:
    ```bash
    git clone https://github.com/acheronii/HexChess.git
    cd HexChess
    docker compose up --build
    ```
    Go to localhost:8000 in a browser to use the site locally.
